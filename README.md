# Aplikasi Credit Scoring App

## Deskripsi

Aplikasi **Credit Scoring App** digunakan untuk memprediksi skor kredit berdasarkan data yang diberikan pengguna menggunakan machine learning.

## Cara Setup

1. **Clone repository**
    ```bash
    git clone https://github.com/username/Credit-Scoring-App.git
    cd Credit-Scoring-App
    ```

2. **Buat virtual environment (opsional namun direkomendasikan)**
    ```bash
    python -m venv venv
    source venv/bin/activate  # Untuk Linux/Mac
    venv\Scripts\activate     # Untuk Windows
    ```

3. **Install requirements**
    ```bash
    pip install -r requirements.txt
    ```

4. **Jalankan aplikasi**
    ```bash
    streamlit run credit_scoring_app.py
    ```

Akses aplikasi melalui browser di alamat yang tertera pada terminal (biasanya http://localhost:8501).

## Catatan

- Pastikan Python sudah terinstall (disarankan versi 3.7 ke atas).
- Jika ada masalah saat instalasi, pastikan pip sudah terupdate.
